# Fonts

| File | Font | Licence |
|---|---|---|
| `Onest.woff2` | Onest, variable weight | SIL Open Font License 1.1, see `OFL-onest.txt` |
| `GeistMono.woff2` | Geist Mono, variable weight | SIL Open Font License 1.1, see `OFL-geistmono.txt` |
| `PowerlineSymbols.otf` | 7 arrow and branch symbols for shell prompts, used by the terminal | MIT, see `LICENSE-powerline.txt` |

The first 2 files hold the Latin subset. They are served from the binary, so the UI loads no font from another site.
